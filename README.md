## Now shipping

**[Pulse](https://github.com/Regncreative/Pulse)** — Windows observability  
Read-only diagnostics: Event Log activity in plain language, live system health, hardware inventory, and local reports. Observation only. Nothing leaves the machine.  
`Flutter` · `C++20` · `Win32`  
[Repository](https://github.com/Regncreative/Pulse) · [pulse.regncreative.com](https://pulse.regncreative.com)

**[Stash](https://github.com/Regncreative/Stash)** — File shelf for Windows  
Collect, organize, and drag files from the system tray. References only — files stay on disk. Built to sit in Fluent Windows 11 chrome, not as a typical tray utility.  
`Electron` · `React` · `TypeScript`  
[Repository](https://github.com/Regncreative/Stash) · [stash.regncreative.com](https://stash.regncreative.com)

**[Fiyat Avcısı](https://github.com/Regncreative/fiyat-avcisi)** — E-commerce price intelligence  
Track products, store price history, and fire alerts on a target price or percent drop. Auth, dashboard, workers, and a multi-strategy crawler — a product stack, not a scraper script.  
`React` · `Express` · `PostgreSQL` · `Redis`  
[Repository](https://github.com/Regncreative/fiyat-avcisi) · [fiyatavcisi.com](https://fiyatavcisi.com) · [app.fiyatavcisi.com](https://app.fiyatavcisi.com)

## Practice

Regn Software sits between product engineering and visual communication.

The work starts with structure: information hierarchy, material language, and how a surface should behave on the machine it belongs to. It continues through native services, desktop shells, and web platforms. Graphic design here is not a coat of paint — it is how the product is specified, from Windows chrome to marketing sites.

Local-first where it matters. Read-only where the system should not be touched. Interfaces that aim to feel native rather than decorative.
